# EzzGameBOOST (ایزی‌گیم‌بوست)

ابزار گیمینگ اندروید

- بوست RAM و پایش زنده‌ی RAM، باتری، حافظه و دما
- تغییر واقعی DNS (رادار گیم، الکترو، شکن، بگذر، شلتر، Cloudflare، Google، Quad9، AdGuard) با VPN محلی مخصوص DNS
- «پیدا کردن سریع‌ترین DNS و اتصال»، اتصال خودکار هنگام اجرای بازی، دکمه‌ی قطع در نوتیفیکیشن و کاشی تنظیمات سریع
- تست پینگ با ذخیره‌ی سرورهای بازی و تاریخچه‌ی کیفیت شبکه به تفکیک ساعت
- کتابخانه‌ی بازی‌ها با زمان بازی، علاقه‌مندی‌ها و ویجت صفحه‌ی اصلی
- رابط فارسی و انگلیسی

## ساخت APK
فایل‌ها را در GitHub آپلود کن، به تب **Actions** برو و APK را از **Artifacts** بگیر.
برای انتشار: **Releases ← Draft a new release** (یک تگ مثل `v2.1.0` بساز و Publish کن)؛ APK خودکار به همان Release اضافه می‌شود.

## کانفیگ وایرگارد تب DNS (EzzViP)
فایل `dns-wireguard.json` در ریشه‌ی ریپو را ویرایش کن؛ کانفیگ‌ها خودکار (حداکثر هر ساعت یک‌بار، یا با دکمه‌ی «به‌روزرسانی کانفیگ‌ها») در تب DNS ← بخش کانفیگ گیمینگ رایگان برای همه‌ی کاربران نمایش داده می‌شوند.

نمونه‌ی یک مورد داخل `configs`:

```json
{ "name": "Ezz1", "displayName": "Ezz 1", "conf": "[Interface]\nAddress = ...\nPrivateKey = ...\n\n[Peer]\nPublicKey = ...\nAllowedIPs = 0.0.0.0/0\nEndpoint = host:port\n" }
```

- هر کانفیگی که از فایل حذف شود، از گوشی کاربران هم پاک می‌شود.
- تست هر سرور وایرگارد (اشتراک ویژه، تب DNS و تب VPN) پکت‌لاس، سرعت دانلود و آپلود را هم نشان می‌دهد.
- تب DNS ← DNGaming: کاربر DNS دلخواه IPv4/IPv6 وارد می‌کند، تست می‌کند و وصل می‌شود.

## تب PRO DNS (جای تب EzzGaming)
لیست DNS در فایل `dns-gaming-pro.json` (ریشه‌ی ریپو) است و اپ آن را حداکثر ساعتی یک‌بار می‌گیرد.
با یک دکمه‌ی «اتصال به بهترین DNS»: ۱) IP گوشی روی سرور اشتراک ثبت می‌شود (خود سرور IP را از اتصال می‌خواند؛ `api.php?a=ip`) ۲) همه‌ی DNSها دو بار تست می‌شوند ۳) به سریع‌ترین وصل می‌شود. اگر ثبت IP ناموفق باشد، تست و اتصال انجام نمی‌شود.

با عوض شدن شبکه (وای‌فای ↔ دیتا) IP دوباره خودکار ثبت می‌شود؛ اگر DNS وصل باشد، بهترین DNS برای IP جدید هم دوباره انتخاب و وصل می‌شود.

نیازی به `register.url` نیست. نسخه‌ی جدید `api.php` (اکشن `ip`) باید روی هاست باشد.

لیست DNSها، نام سرور و IP به کاربر نمایش داده نمی‌شود؛ کاربر فقط دکمه‌ی «اتصال به بهترین DNS» را می‌بیند.

### تایید IP توسط مدیر
- کاربر با «📍 ثبت IP» (یا خودکار با اتصال و با هر تغییر شبکه) IP خودش را ثبت می‌کند؛ اگر ثبت شود می‌نویسد «با موفقیت ثبت شد».
- هر IP جدید در پنل مدیریت (تب «تایید IP» و کارت هر کاربر) «در انتظار تایید» است. تا مدیر تایید نکند، اپ تست و اتصال DNS را انجام نمی‌دهد.
- مدیر می‌تواند IP را تایید، رد، حذف یا فقط یکی را فعال کند، و IP دستی هم اضافه کند.
- برای اینکه سرور DNS فقط IPهای تاییدشده را قبول کند، در `config.php` کلید `wl_key` بگذار و آدرس `api.php?a=wl&k=کلید` را به وایت‌لیست سرور DNS بده.

### انتخاب بهترین DNS (IPv4 و IPv6)
دکمه‌ی «اتصال به بهترین DNS» و دکمه‌ی «شروع تست پینگ و سرعت» هر دو یک کار را انجام می‌دهند: ۱) ثبت IP (باید تایید شده باشد) ۲) تست همه‌ی آدرس‌های همه‌ی DNSها، چه IPv4 و چه IPv6، با ۳ بار تست روی اپراتور خود کاربر ۳) وصل شدن به بهترین از «تونل بازی» (فقط بازی‌ها از تونل رد می‌شوند؛ بازی‌ای که روی گوشی نصب است یا علاقه‌مند شده). در `dns-gaming-pro.json` هر مورد می‌تواند IPv4 و IPv6 قاطی داشته باشد.

### تست پینگ و سرعت
بعد از وصل شدن، کارت «PING & SPEED» پینگ زنده (نمودار) و سرعت دانلود و آپلود را نشان می‌دهد؛ نام و IP سرور نمایش داده نمی‌شود.

### صفحه‌ی اشتراک ویژه
نام بازی‌های آنلاین موبایل با فونت Black Ops One (مجوز OFL، فایل در `app/src/main/assets/fonts`) روی کارت شیشه‌ای با درخشش متحرک نمایش داده می‌شود.
