# EzzGameBOOST (ایزی‌گیم‌بوست)

ابزار گیمینگ اندروید ساخته‌شده توسط **ایزی دیجی (EzzDigi)** — https://ezzdigi.com

- بوست RAM و پایش زنده‌ی RAM، باتری، حافظه و دما
- تغییر واقعی DNS (رادار گیم، الکترو، شکن، بگذر، شلتر، Cloudflare، Google، Quad9، AdGuard) با VPN محلی مخصوص DNS
- «پیدا کردن سریع‌ترین DNS و اتصال»، اتصال خودکار هنگام اجرای بازی، دکمه‌ی قطع در نوتیفیکیشن و کاشی تنظیمات سریع
- تست پینگ با ذخیره‌ی سرورهای بازی و تاریخچه‌ی کیفیت شبکه به تفکیک ساعت
- کتابخانه‌ی بازی‌ها با زمان بازی، علاقه‌مندی‌ها و ویجت صفحه‌ی اصلی
- رابط فارسی و انگلیسی

## ساخت APK
فایل‌ها را در GitHub آپلود کن، به تب **Actions** برو و APK را از **Artifacts** بگیر.
برای انتشار: **Releases ← Draft a new release** (یک تگ مثل `v2.1.0` بساز و Publish کن)؛ APK خودکار به همان Release اضافه می‌شود.
