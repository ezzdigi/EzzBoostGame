📖 آموزش کامل کار با پنل EzzDigi
🎮 قبل از شروع
این پنل برای انتخاب DNS، ساخت کانفیگ و استفاده از DNS روی دستگاه‌های مختلف طراحی شده است. ابتدا روش موردنظر خودت را انتخاب کن، DNS یا لوکیشن را مشخص کن و در پایان از گزینه‌های کپی متن یا دانلود فایل استفاده کن.

نکته: عدد اول DNS = Primary / DNS اصلی و عدد دوم = Secondary / DNS ثانویه است. آدرس‌ها را دقیقاً همان‌طور که در پنل نمایش داده می‌شوند وارد کن.
🟢 ۱. شروع کار با پنل
مرحله ۱: از بالای پنل یکی از تب‌ها را انتخاب کن.
مرحله ۲: بسته به کاری که می‌خواهی انجام بدهی، DNS عمومی، اپراتور، DNS دلخواه، لوکیشن یا تولید خودکار را انتخاب کن.
مرحله ۳: گزینه‌های نمایش‌داده‌شده را بررسی و DNS موردنظر را انتخاب کن.
مرحله ۴: روی ساخت کانفیگ بزن.
مرحله ۵: نتیجه در کادر کانفیگ نمایش داده می‌شود؛ سپس می‌توانی آن را کپی کنی یا به‌صورت فایل دانلود کنی.

💡 اگر فقط می‌خواهی DNS را روی گوشی، کامپیوتر، کنسول یا روتر تنظیم کنی، لازم نیست حتماً کانفیگ WireGuard بسازی؛ می‌توانی DNS را از تب مربوطه برداری و دستی وارد کنی.
🟢 ۲. تب «تولید خودکار»
این بخش برای ساخت سریع کانفیگ طراحی شده است.

1. وارد تب تولید خودکار شو.
2. در صورت وجود گزینه‌های انتخابی، موارد موردنظر را مشخص کن.
3. روی ساخت کانفیگ بزن تا کانفیگ جدید ساخته شود.
4. متن تولیدشده را در کادر پایین بررسی کن.
5. برای انتقال سریع متن از کپی متن و برای استفاده در WireGuard از دانلود فایل استفاده کن.

🔄 اگر چند سرور در پنل در دسترس باشد، هنگام ساخت کانفیگ می‌توانی سرورهای مختلف را تست کنی تا ببینی کدام گزینه برای اتصال تو بهتر جواب می‌دهد.
🟢 ۳. تب «انتخاب لوکیشن»
اگر می‌خواهی قبل از ساخت کانفیگ لوکیشن و DNS مربوط به آن را انتخاب کنی، از این بخش استفاده کن.

1. تب انتخاب لوکیشن را باز کن.
2. لوکیشن موردنظر را انتخاب کن.
3. از لیست نمایش‌داده‌شده DNS مناسب را انتخاب کن.
4. روی ساخت کانفیگ بزن.
5. بعد از ساخته‌شدن، از کپی متن یا دانلود فایل استفاده کن.

💡 بهتر است چند گزینه را تست کنی؛ نزدیک‌ترین لوکیشن همیشه الزاماً بهترین نتیجه را برای همه‌ی اینترنت‌ها و اپراتورها نمی‌دهد.
🟢 ۴. تب «DNS عمومی»
این بخش برای انتخاب سریع DNSهای عمومی موجود در پنل است.

1. وارد DNS عمومی شو.
2. DNS موردنظر را از لیست انتخاب کن.
3. در صورت نیاز روی ساخت کانفیگ بزن.
4. کانفیگ را کپی یا دانلود کن.

اگر هدف تو فقط تنظیم DNS دستگاه است، همان آدرس‌های Primary و Secondary نمایش‌داده‌شده را بردار و طبق آموزش دستگاه خودت وارد کن.
🟢 ۵. تب «DNS اپراتورها»
این قسمت برای انتخاب DNS بر اساس اپراتور طراحی شده است.

1. وارد تب DNS اپراتورها شو.
2. در صورت فعال بودن تشخیص خودکار، اجازه بده اپراتور شناسایی شود.
3. اگر لازم بود، اپراتور را به‌صورت دستی انتخاب کن.
4. DNSهای مربوط به آن بخش را بررسی و گزینه موردنظر را انتخاب کن.
5. در صورت نیاز ساخت کانفیگ را بزن و سپس کپی یا دانلود کن.

💡 اگر یک DNS نتیجه خوبی نداد، گزینه دیگری از همان بخش را تست کن؛ کیفیت مسیر DNS می‌تواند به شبکه و محل اتصال بستگی داشته باشد.
🟢 ۶. تب «DNS دلخواه»
اگر DNS خاصی داری که در لیست پنل نیست، از این قسمت استفاده کن.

1. وارد DNS دلخواه شو.
2. DNS اصلی و ثانویه را وارد کن؛ برای نمونه: 8.8.8.8, 8.8.4.4
3. فاصله یا کاراکتر اضافی وارد نکن و آدرس‌ها را درست بنویس.
4. روی ساخت کانفیگ بزن.
5. نتیجه را کپی یا دانلود کن.
🟢 ۷. تب «وایفای»
این بخش برای انتخاب DNS متناسب با سرویس/وای‌فای و ساخت خروجی مربوط به آن است.

1. وارد تب وایفای شو.
2. سرویس موردنظر را انتخاب کن.
3. DNS موردنظر را از لیست انتخاب کن.
4. DNS انتخاب‌شده را بررسی کن.
5. روی ساخت کانفیگ بزن و سپس خروجی را کپی یا دانلود کن.
🟢 ۸. ساخت کانفیگ، کپی و دانلود چه فرقی دارند؟
ساخت کانفیگ: خروجی WireGuard را با انتخاب‌های فعلی پنل تولید می‌کند.
کپی متن: متن کانفیگ را برای استفاده یا انتقال دستی در کلیپ‌بورد کپی می‌کند.
دانلود فایل: کانفیگ را به‌صورت فایل تنظیمات WireGuard ذخیره می‌کند تا بتوانی آن را در برنام کانفیگه WireGuard وارد کنی.

⚠️ اگر قصد Import کردن در WireGuard را داری، بهتر است از دانلود فایل استفاده کنی و فایل دانلودشده را مستقیماً در WireGuard وارد کنی.
🟢 ۹. آموزش کامل WireGuard
۱) ابتدا از پنل لوکیشن/سرور و DNS موردنظر را انتخاب کن.
۲) روی ساخت کانفیگ بزن.
۳) روی دانلود فایل بزن تا فایل کانفیگ ذخیره شود.
۴) برنام کانفیگه WireGuard را در دستگاه باز کن.
۵) گزینه + را بزن و گزینه Import از فایل/فایل کانفیگ را انتخاب کن.
۶) فایل دانلودشده از پنل را انتخاب کن.
۷) تونل ساخته‌شده را فعال کن.
۸) اتصال را تست کن و در صورت نیاز سرور یا DNS دیگری را امتحان کن.

📱 WireGuard برای اندروید و آیفون و همچنین ویندوز و مک قابل استفاده است. برای بازکردن و دانلود فایل از مرورگر Chrome استفاده کن.
🟢 ۱۰. انتخاب نام کانفیگ فایل / کانفیگ
اگر پنل برای نام کانفیگ‌گذاری فایل از تو نام کانفیگ می‌خواهد، نام کانفیگ را کوتاه و ساده انتخاب کن.

✅ بهتر است از حروف انگلیسی کوچک، عدد و کاراکترهای ساده استفاده شود.
❌ از نام کانفیگ فارسی، فاصله و کاراکترهای عجیب استفاده نکن.
💡 نام کانفیگی انتخاب کن که با فایل‌های دیگر اشتباه نشود؛ مثلاً server1 یا ezz1.
🟢 ۱۱. اندروید — تنظیم DNS روی Wi‑Fi
1. Settings → Wi‑Fi را باز کن.
2. روی شبکه‌ای که به آن متصل هستی بزن یا آیکون ⚙️ را انتخاب کن.
3. Edit network یا گزینه مشابه را باز کن.
4. Advanced options را باز کن.
5. IP settings را از DHCP به Static تغییر بده؛ نام کانفیگ گزینه‌ها ممکن است با مدل گوشی فرق کند.
6. فیلدهای DNS 1 و DNS 2 را با DNS انتخابی پنل پر کن.
7. Save را بزن.

📱 روی دیتای سیم‌کارت، بسیاری از گوشی‌ها اجازه تنظیم مستقیم DNS را نمی‌دهند. در این حالت می‌توانی از برنام کانفیگه‌های DNS Changer که از VPN محلی استفاده می‌کنند کمک بگیری.
🟢 ۱۲. آیفون — تنظیم DNS روی Wi‑Fi
1. Settings → Wi‑Fi
2. روی علامت ⓘ کنار شبکه متصل بزن.
3. Configure DNS را انتخاب کن.
4. حالت را روی Manual بگذار.
5. DNSهای قبلی را در صورت نیاز حذف کن و DNSهای پنل را با + اضافه کن.
6. روی Save بزن.
🟢 ۱۳. ویندوز — تنظیم DNS
1. روی آیکون اینترنت کنار ساعت کلیک راست کن → Network & Internet settings.
2. شبکه متصل را انتخاب کن.
3. بخش تنظیم DNS را پیدا کن و روی Edit کنار DNS server assignment بزن.
4. حالت را از Automatic به Manual تغییر بده و IPv4 را فعال کن.
5. DNS اصلی و ثانویه را وارد و Save کن.
6. برای تازه‌سازی DNS می‌توانی در Command Prompt دستور ipconfig /flushdns را اجرا کنی.

⚠️ بعضی VPNها DNS سیستم را تغییر می‌دهند؛ هنگام تست، تنظیمات VPN را هم در نظر بگیر.
🟢 ۱۴. وای‌فای / روتر
1. آدرس مدیریت روتر را در مرورگر باز کن؛ معمولاً 192.168.1.1 یا 192.168.0.1 است و ممکن است روی برچسب روتر نوشته شده باشد.
2. با نام کانفیگ کاربری و رمز روتر وارد شو.
3. بخش WAN، Internet Settings یا DNS Settings را پیدا کن.
4. DNS را از حالت خودکار به دستی تغییر بده.
5. DNS اصلی و ثانویه را وارد کن.
6. تنظیمات را ذخیره کن و در صورت نیاز روتر را راه‌اندازی مجدد کن.

💡 تنظیم DNS روی روتر می‌تواند باعث شود دستگاه‌های متصل به همان شبکه از تنظیم DNS روتر استفاده کنند.
🟢 ۱۵. PS5
1. Settings → Network → Settings برو.
2. Set Up Internet Connection را انتخاب کن.
3. شبکه موردنظر را انتخاب و Advanced Settings را باز کن.
4. DNS Settings را از Automatic به Manual تغییر بده.
5. Primary DNS و Secondary DNS را وارد کن.
6. ادامه تنظیمات شبکه را در صورت نداشتن نیاز خاص روی حالت پیش‌فرض نگه دار و اتصال را تست کن.
🟢 ۱۶. Xbox
1. دکمه Xbox را بزن → Profile & system → Settings.
2. General → Network settings.
3. Advanced settings → DNS settings.
4. حالت Manual را انتخاب کن.
5. Primary و Secondary DNS را وارد و ذخیره کن.
🟢 ۱۷. تب «DNS Changer»
اگر نمی‌خواهی DNS را از تنظیمات سیستم به‌صورت دستی تغییر بدهی، از بخش DNS Changer استفاده کن.

1. وارد تب DNS Changer شو.
2. DNS موردنظر را انتخاب یا وارد کن.
3. سرویس را فعال کن و در صورت درخواست سیستم، اجازه ایجاد VPN محلی را تأیید کن.
4. بعد از فعال‌شدن، اتصال بازی یا اینترنت را تست کن.

⚠️ DNS Changer لزوماً به معنی VPN اینترنتی نیست؛ معمولاً برای اعمال DNS از یک اتصال VPN محلی در دستگاه استفاده می‌شود.
🟢 ۱۸. برای بازی کدام گزینه را انتخاب کنم؟
اگر هدف اصلی تو بازی است، ابتدا گزینه‌ای را انتخاب کن که با نوع اتصال و اپراتورت سازگارتر است.

برای WireGuard: از تولید خودکار/لوکیشن و سپس دانلود فایل استفاده کن.
برای تغییر مستقیم DNS: از DNS عمومی، DNS اپراتورها یا DNS دلخواه استفاده کن.
برای گوشی: می‌توانی DNS را دستی روی Wi‑Fi تنظیم کنی یا از DNS Changer استفاده کنی.
برای روتر: DNS را در تنظیمات WAN/Internet روتر وارد کن.

🎯 برای پیدا کردن گزینه مناسب، چند DNS و در صورت وجود چند سرور را تست کن و فقط نتیجه واقعی روی اینترنت خودت را معیار قرار بده.
🟢 ۱۹. اگر اتصال یا DNS کار نکرد چه کنیم؟
اگر WireGuard وصل نمی‌شود: فایل دانلودشده را دوباره وارد کن و یک سرور/لوکیشن دیگر را امتحان کن.
اگر DNS نتیجه خوبی نداد: DNS دیگری از همان تب یا یک لوکیشن دیگر را تست کن.
اگر سایت‌ها باز نمی‌شوند: DNS واردشده را از نظر اعداد و نقطه‌ها بررسی کن و تنظیمات قبلی را برگردان.
اگر بازی به اینترنت وصل نمی‌شود: DNS یا سرور دیگری را امتحان کن و در صورت استفاده از VPN، تداخل سرویس‌ها را بررسی کن.
اگر فایل در WireGuard وارد نمی‌شود: مطمئن شو فایل کامل دانلود شده و آن را به‌صورت فایل کانفیگ وارد می‌کنی، نه اینکه فقط متن را داخل برنام کانفیگه اشتباه وارد کنی.

⚠️ عملکرد DNS و سرور برای همه کاربران یکسان نیست؛ ممکن است یک گزینه برای یک اینترنت بهتر و برای اینترنت دیگر ضعیف‌تر باشد.
🟢 ۲۰. خلاصه سریع برای کاربر
می‌خواهی کانفیگ WireGuard بسازی؟
تب مناسب → انتخاب DNS/لوکیشن/سرور → ساخت کانفیگ → دانلود فایل → Import در WireGuard → فعال‌سازی و تست.

می‌خواهی فقط DNS عوض کنی؟
تب DNS مناسب → انتخاب Primary و Secondary → واردکردن در گوشی/کامپیوتر/روتر/کنسول یا استفاده از DNS Changer.

نتیجه خوب نبود؟
گزینه دیگری را تست کن. بهترین DNS یا سرور برای بازی به مسیر و شرایط اتصال فعلی بستگی دارد.
🎮 پیشنهاد EzzDigi:
برای رسیدن به بهترین نتیجه، فقط به اسم لوکیشن یا DNS اکتفا نکن؛ چند گزینه را روی همان اینترنتی که با آن بازی می‌کنی امتحان کن و گزینه‌ای را نگه دار که در عمل اتصال پایدارتر و تجربه بهتری به تو می‌دهد.
DNS موردنظر را انتخاب کن و با دکمه «کپی» سریع کپی کن.
